# 安卓追平 iOS：玩家可见的差距表

目标：安卓端达到目前 iOS 端同等质量。这张表从「玩家拿到手能不能用」的角度列差距，和 #48（安卓直连技术总表，按批列性能与缺陷）互补：#48 管每一项怎么做，这里管做完以后玩家那一侧还差什么。进度在总进度 PR 里勾选，认领以 #48 和该 PR 里维护方的确认为准。

基线：main `eb2ec033`（2026-11-10）。「安卓现状」每一格都对过这个提交的代码或当天的真机局；没核的写「未核」。

## 外部 PR 合入顺序（建议）

按「默认关 / 只改出包的先收，互相依赖的按依赖顺序」排。和最新 main 的合并在本地都试过（`git merge-tree`，2026-11-10，main `eb2ec033`），六个都没有文本冲突。

1. #504 社区补丁出包交表（wwmogu）：只改出包，不设开关时产物逐字节不变。
2. #501 计算管线缓存默认开（n06ody）：有 A/B 读数。
3. #512 计算着色器程序级缓存（n06ody）：依赖 #501，默认关。
4. #160 真机「装包 → 起局 → 报告」闭环 + 设备锁（n06ody）：后面每一项的真机验收都要用它。
5. #511 共用直连库运行时读面（n06ody）：默认关，碰共用的 `graphics/nvn/`。
6. #232 VP9 硬解（n06ody）：默认关，体量最大，碰共用解码路径。

## 怎么认领

- 表里「待认领」的项，在总进度 PR 或 #48 里回一句要做哪一项；一个 PR 只做一件事，写 `Part of #48`。
- 没有真机也能做：大多数项可以在宿主上做红绿。真机读数请写明机型、SoC、系统版本、是否接电。
- 约束见 [AGENTS.md](AGENTS.md)：安卓只做直连，新能力优先做到共用层，先查 [安卓接入矩阵](../docs/安卓接入矩阵.md) 接现成的共用件。
